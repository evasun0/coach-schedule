🏸 教练排课表

使用说明 & 常见问题

📖 基本操作

添加课程

1点击底部 ＋ 添加课程
2填写日期、时间、学员姓名
3输入课时费和场地费（可选）
4勾选 消耗该学员1课时（请假取消勾选）
5重复添加选择周数，或选自定义输入
5点 保存 完成

编辑/删除课程

点击日视图或周视图中的课程卡片 → 修改信息 → 保存或删除

快速添加

在日视图空白时间块上点一下，自动填入该时段

👀 三种视图

顶部标签切换：

  • 日视图 — 按半小时格显示当天课程，左右箭头翻日期
  • 周视图 — 一周七天并列，显示每天课程和费用
  • 月视图 — 整月日历，点击某天跳到日视图

👤 学员管理

菜单 → 管理学员

  • 添加学员时填写：姓名、总课时、课时费
  • 点击学员可修改姓名/总课时/课时费
  • 右侧显示 剩余X节
  • 每节课保存时勾选"消耗课时"自动扣减

请假处理

如果学员请假没来：

  • 编辑课程 → 取消勾选"消耗该学员1课时" → 保存
  • 课时会自动归还，课程记录保留

💰 收益统计

菜单 → 收益统计

  • 显示课程总数、课时费收入、场地费支出、净收入
  • 可按本周/本月/近3个月查看
  • 也可 自定义日期范围 统计
  • 下方显示折线图和学员明细

⏰ 课前提醒

页面打开时自动检查接下来1小时内的课程，顶部显示黄色提醒条

  • 注意 关闭页面后提醒不工作（浏览器限制）
  • 建议每次查看课程表时留意提醒条

🏟️ 场地费管理

菜单 → 场地费管理

  • 预先设置各个场馆不同时段的费用
  • 添加课程时自动出现下拉建议

💾 数据备份

重要 数据存在手机本地，换手机或清浏览器会丢失！

如何备份

菜单 → 导出课表 → 下载 .json 文件

如何恢复

菜单 → 导入课表 → 选择备份文件 → 导入

备份提醒

打开菜单底部会显示上次备份时间：

  • 今天已备份 ✅
  • 3天前备份 ⚠️
  • 7天以上未备份 ❌

建议：每周导出一次，备份文件存到微信收藏

📅 导出日历

菜单 → 导出日历(.ics) → 可导入手机系统日历

🧪 测试数据

菜单 → 导入测试数据 → 一键生成8名学员+57节课，方便体验全部功能

ℹ️ 常见问题

数据存在哪里？

全部存在 手机浏览器本地，不会上传到任何服务器，隐私安全。

换了手机怎么迁移？

旧手机导出 → 发到新手机 → 新手机导入

离线能用吗？

打开过一次后，没网络也能看已加载的页面。

我想在电脑上管理可以吗？

直接用电脑浏览器打开 https://evasun0.github.io/coach-schedule/ 即可，数据是分开的（电脑和手机数据不互通）。

删除课程会还课时吗？

会的！删除已扣课时的课程，自动归还1课时。

学员列表太长怎么办？

菜单里的学员列表默认收起，点击展开。
